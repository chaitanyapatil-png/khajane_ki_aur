# 🏆 Khajane Ki Aur – Season 2

**Khajane Ki Aur – Season 2** is an interactive, web-based puzzle game designed for a private event. Participants solve real-world or in-game clues to discover the correct password, which is then entered on the website to unlock the next stage of the adventure.

The project focuses on creating an engaging puzzle-solving experience through a clean interface, immersive animations, and secure password verification.

## ✨ Features

* 🔐 Password-based challenge system
* 🧩 Progressive clue-solving gameplay
* 📦 Interactive treasure chest unlocking animation
* 🎨 Responsive and modern user interface
* ⚡ Fast and lightweight web application
* 🔊 Optional sound effects and visual feedback
* 📱 Mobile-friendly design

## 🎮 Gameplay

1. Participants receive clues during the event.
2. They analyze the clues to determine the correct password.
3. The password is entered on the website.
4. If the password is correct, the chest unlocks and reveals the next stage or reward.
5. Incorrect passwords prompt the participant to continue solving the clues.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

This project was created for a **private event** to provide participants with an interactive puzzle-solving experience. It is intended for educational and entertainment purposes and demonstrates front-end web development concepts, user interaction, and game mechanics.
